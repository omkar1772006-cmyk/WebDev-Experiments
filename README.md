# 📚 PageNest – Online Bookstore Website

PageNest is a web development project that provides a simple and
user-friendly interface for an online bookstore. It allows users to
explore book-related pages through a clean layout and organized
navigation.

The project is developed using HTML and CSS as part of a Web Development
learning project.

---

## ✨ Features

- 🏠 Home Page – Landing page for the website.
- 📚 Book Catalogue – Displays books in an organized layout.
- 🗂️ Categories Page – Organizes books into different categories.
- 🛒 Shopping Cart – Displays book names, prices, quantities, and totals.
- 🔐 Login Page – Provides a login interface.
- 📝 Registration Page – Provides a user registration interface.
- 🎨 Responsive Styling – Uses CSS to style the website.
- 🖼️ Custom Branding – Includes the PageNest logo.

---

## 🛠️ Technologies Used

- HTML5 – Website structure and content.
- CSS3 – Styling, layout, colours, and visual design.
- Git – Version control.
- GitHub – Source code hosting and project management.
